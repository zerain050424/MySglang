## 2. 逐格判读

### R3（10/30/90 异构 idle）— 目标场景

级联被完全消除，且没有付出代价：

| | 基线 | DRR |
|---|---|---|
| wipe | 4（全在 cold 组） | **0** |
| `HHI(组)` | 1.00 | —（无 wipe） |
| cold 命中 | **0.012** | **0.684** |
| resume p99 | 265.5 ms | **162.7 ms** |
| 全局 p99 | 195.2 ms | **158.7 ms** |
| 全局命中率 | 88.11% | **89.35%** |

### R2（三组同 90s，长 idle）— 同质压力场景

基线在这里伤害最大（9 次 wipe、`HHI=0.56`、p99 461ms），DRR 收益也最大：

| | 基线 | DRR |
|---|---|---|
| wipe / HHI(组) | 9 / 0.56 | **0** / — |
| 三组命中 | 0.633 / 0.742 / 0.552 | **0.670 / 0.628 / 0.651**（均匀） |
| p99 | 461.1 ms | **145.4 ms（−68%）** |
| 全局命中率 | 82.09% | **88.20%（+6.1pt）** |

### R1（三组同 30s，轻压力）— 对照格

两版都无 wipe、命中率都在 89–90%，但 **DRR 略差**：

| | 基线 | DRR |
|---|---|---|
| wipe | 0 | 0 |
| p99 | 104.8 ms | 161.6 ms（+54%） |
| resume p99 | 75.0 ms | 91.2 ms |
| 全局命中率 | 89.93% | 89.43%（−0.5pt） |

原因：R1 压力很轻，基线本来就把淘汰压在便宜的 text 内容上、几乎不碰 agentic；
DRR 把损失主动摊给所有 agentic 会话，于是**给本来均衡的局面引入了人为损失**。

## 3. 结论

1. **DRR 是"最坏情况工具"**：压力越大、idle 越异质，收益越大（R2 −68%、R3 −39% 的 p99）；
   在压力轻、局面本来就均衡时是净损失（R1 +54% p99）。
2. 收益不依赖 `P`：纯轮询（`P≡1`）已经把 wipe 压到 0。
3. 代价侧：p50 三格都 +1~2 ms；命中率在 R1/R3 小幅波动（−0.5 / +1.2pt），R2 大涨（+6.1pt）。
4. 护栏触发一次：R3 的 `d_max=992 > κ·L=950`，走的是放宽路径（为保证淘汰可推进）。

## 4. 下一步建议（S2c）

DRR 需要一个**启用条件**，避免在 R1 那种局面下白付代价：

```
仅当检测到集中化趋势时才切到 DRR，例如
    max_i d_i > θ · L_i        （某会话缺口已过半条链）
  或 单次 evict 循环里同一会话被连续选中 > k 次
否则保持原 victim_key 全局最小
```

判据：R3/R2 的收益不变（wipe=0、p99 不回升），R1 的 p99 回到 ≤110 ms。
